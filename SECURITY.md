# Security Policy

Zaphod is a local developer tool that runs Git operations in user repositories.
Safety issues that could cause unexpected data loss, repository corruption, or
execution of unintended commands are treated seriously.

## Reporting a Vulnerability

Please report vulnerabilities using GitHub Security Advisories for this
repository when available.

If advisories are not available, open an issue with minimal public detail and a
maintainer will coordinate a private follow-up path.

## Supported Versions

Zaphod has not shipped a stable release yet. Security fixes will target the
latest development branch until versioned releases begin.
